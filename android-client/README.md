# Rust Remote PC - Android Mobile Client (Kotlin)

আপনার পিসির স্ক্রিন শেয়ার সরাসরি অ্যান্ড্রয়েড মোবাইল ফোনে দেখা এবং মোবাইল থেকে পিসি কন্ট্রোল করার জন্য তৈরি করা একটি সিম্পল ও মডার্ন অ্যান্ড্রয়েড অ্যাপ (Jetpack Compose & Kotlin চালিত)।

---

## 📱 প্রধান ফিচারসমূহ (Features)

1. **সিম্পল ও মডার্ন ডার্ক UI (Jetpack Compose & Material 3):**
   - স্লিক ডার্ক থিম (`#0A0F1D`), সাইয়ান ও ইন্ডিগো অ্যাকসেন্ট।
   - পিসির Tailscale IP / Local Wi-Fi IP, Port (Default: 5885) এবং Password দিয়ে ১-ট্যাপে কানেক্ট করার সুবিধা।
   - রিসেন্ট কানেকশন হিস্ট্রি (অটো-সেভ)।

2. **হাই-স্পিড লো-ল্যাটেন্সি স্ক্রিন স্ট্রিমিং:**
   - পিসির স্ক্রিন ফ্রেম রিয়েল-টাইমে মোবাইলের ফুলস্ক্রিনে স্ট্রিম হয়।
   - হার্ডওয়্যার এক্সিলারেটেড ডিকোডিং ও রেন্ডারিং।
   - লাইভ পারফরম্যান্স HUD: **FPS কাউন্টার**, **Latency / Ping (ms)** এবং **পিসির রেজোলিউশন** ডিসপ্লে।

3. **স্মুথ পিঞ্চ-টু-জুম ও প্যানিং:**
   - মোবাইল স্ক্রিনে পিসির ছোট লেখা/আইকন সহজে দেখতে ২ আঙুলে জুম (১x থেকে ৫x) এবং যেকোনো দিকে প্যান করার সুবিধা।
   - "Reset Zoom" বাটনে এক ক্লিকে স্ক্রিন রিসেট।

4. **২টি টাচ মোড (Touch Modes):**
   - **Virtual Trackpad Mode:** ল্যাপটপের টাচপ্যাডের মতো আঙুল ঘুরিয়ে মাউস কার্সর মুভ করা, ট্যাপে লেফট ক্লিক, ডাবল ট্যাপে ডাবল ক্লিক, এবং লং প্রেস বা ২ আঙুলে রাইট ক্লিক।
   - **Direct Touch Mode:** মোবাইলের টাচস্ক্রিনে যেখানে হাত দেবেন, পিসির মাউস সরাসরি সেই পিক্সেল পয়েন্টে ক্লিক করবে (টাচ মনিটরের মতো)।

5. **ভাসমান কুইক টুলবার (Floating Quick Toolbar):**
   - মাউস ক্লিক বাটন: **L-Click**, **R-Click**, **D-Click**।
   - কিবোর্ড টেক্সট টাইপিং ডায়ালগ: মোবাইল কিবোর্ড দিয়ে টাইপ করে যেকোনো টেক্সট একবারে বা ক্যারেক্টার অনুযায়ী পিসিতে পাঠানো।
   - স্পেশাল উইন্ডোজ কি: **Windows Key (Win)**, **Esc**, **Enter**, **Backspace**, **Tab**, **Ctrl+C (Copy)**, **Ctrl+V (Paste)**।
   - ডিসকানেক্ট বাটন।

6. **Screen Keep-Alive:**
   - রিমোট স্ক্রিন দেখার সময় ফোনের স্ক্রিন বন্ধ/স্লিপ হয়ে যাওয়া বন্ধ রাখে।

## 🛠️ বিল্ড ও ইনস্টল করার নিয়ম (How to Build & Install)

### তৈরি করা প্রস্তুত APK ফাইল:
রেডিমেড ডিবাগ APK ফাইলটি ইতিমধ্যে বিল্ড করা হয়েছে:
- ফাইল লোকেশন: `android-client/app/build/outputs/apk/debug/app-debug.apk`

### ১. মোবাইল ফোনে ইনস্টল করা (via USB ADB):
আপনার মোবাইল ফোনে **Developer Options** এবং **USB Debugging** চালু করে পিসির সাথে ইউএসবি ক্যাবল লাগান:
```powershell
adb install -r "D:\projects\rust-remote-pc\android-client\app\build\outputs\apk\debug\app-debug.apk"
```

### ২. পুনরায় বিল্ড করতে চাইলে (Gradle):
```powershell
cd D:\projects\rust-remote-pc\android-client
.\gradlew.bat assembleDebug
```

## 🚀 ব্যবহারের নিয়ম (How to Use)

১. **পিসিতে Host চালু করুন:**
   ```powershell
   cargo run --release -- host --bind 0.0.0.0:5885 --password "mysecret123" --fps 30
   ```
২. **মোবাইল ফোনে "Rust Remote PC" অ্যাপটি ওপেন করুন:**
   - **PC IP Address:** আপনার পিসির Tailscale IP (যেমন: `100.x.y.z`) অথবা একই Wi-Fi-তে থাকলে লোকাল আইপি (যেমন: `192.168.1.10`) দিন।
   - **Port:** `5885`
   - **Password:** হোস্ট চালু করার সময় দেওয়া পাসওয়ার্ডটি (যেমন: `mysecret123`) দিন।
৩. **"Connect to PC"** বাটনে ট্যাপ করুন — সঙ্গে সঙ্গে আপনার পিসির স্ক্রিন মোবাইলে দেখতে পাবেন!
